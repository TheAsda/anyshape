# Security

## Reporting a vulnerability

Please report a vulnerability privately, through GitHub's private vulnerability reporting: open the repository's [Security tab](https://github.com/TheAsda/anyshape/security) and choose **Report a vulnerability**, or go straight to the [new advisory form](https://github.com/TheAsda/anyshape/security/advisories/new). Don't open a public issue for it.

Include what you found, the version of `anyshape` it affects, and the steps or code that show it. You'll get a reply in the advisory, and the fix and its release are coordinated there before anything is made public.

## Supported versions

anyshape is in 0.x: fixes go into the latest release only.
