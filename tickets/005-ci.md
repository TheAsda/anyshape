# 005 · CI: run tests and both typechecks on every PR

**Type:** Chore · **Priority:** Medium · **Plan:** NF2

## Why
The type-level tests (`src/types.test.ts`, the `typeOnlyChecks` functions, `@ts-expect-error` lines) only run under `tsc`, not under vitest. Without CI a broken inference can merge while `npm test` is green.

## Scope
A workflow that runs on PRs and `main`:
1. `bun install`, then `bunx playwright install --with-deps chromium` (the React suites run in Chromium via Vitest browser mode)
2. `bun run test` (both projects: `unit` in Node, `react` in the browser)
3. `bun run typecheck`
4. `cd examples/basic && bun run typecheck`

Optionally upload `.vitest/` (failure screenshots) as an artifact when the React project fails.
